Eventia - Crear Evento con Plantillas

Conceptos 
Tramos = agenda/partes del evento en el tiempo (cada tramo puede tener su propia dirección/horario).
Accesos = tipos de invitación (qué combinación de tramos ve/puede confirmar un invitado).
Relaciones acceso–tramo = matriz que define “este acceso incluye estos tramos”. 

1) Qué son los “TRAMOS”
Tramos = partes del evento en el tiempo.
Ejemplo boda:
Tramo 1: Iglesia (19:00)
Tramo 2: Cena (21:00)
Tramo 3: Fiesta (23:00)
Cada tramo puede tener:
hora inicio/fin
lugar/dirección (puede ser distinta)
leyenda/nota visible (“llegar 15 min antes”)
Esto es lo que el invitado ve como “agenda” del evento.

2) Qué son los “ACCESOS”
Accesos = tipos de invitación.
Es “a qué partes está invitada esta persona”.
Ejemplo de boda:
Acceso A: “Solo Iglesia”
Acceso B: “Iglesia + Cena + Fiesta” (el clásico)
Acceso C: “Cena + Fiesta”
Acceso D: “Solo Fiesta”
Cuando invitamos a alguien, le asignamos un acceso.
Ese acceso define automáticamente qué tramos puede ver/confirmar.
Resumiendo:
Tramos = agenda del evento
Accesos = quién está invitado a qué parte de esa agenda

3) Qué es la tabla “acceso_tramos”
Es el “mapa” que dice este acceso incluye este tramo
Ejemplo (boda):
Acceso “Solo Iglesia” incluye tramo “Iglesia”
Acceso “Cena + Fiesta” incluye tramo “Cena” y “Fiesta”
Acceso “Iglesia + Cena + Fiesta” incluye los 3
Esto permite que el front pueda mostrar un “checklist”:
? Iglesia / ? Cena / ? Fiesta

Paso 4- Aplicar la plantilla elegida al evento
Al hacer clic en el botón Aplicar plantilla
Llama al endpoint:
POST /eventos_plantillas/Aplicar?idEvento=8
(dejé el endpoint en la carpeta “Evento - Tramos - Accesos - Relaciones (con Plantilla)”)
Esto es solo un default para que los tramos no nazcan vacíos.

Body (ejemplo para plantilla 2: Iglesia + Cena + Fiesta):
{
  "id_plantilla": 2,
  "borrar_existente": true,
  "fecha_base": "2026-11-22T19:00:00-03:00",
  "lugar_base": "Estancia Santa Clara",
  "direccion_base": "Ruta 2 Km 395",
  "latitud_base": -37.995100,
  "longitud_base": -57.573400
}
Backend automáticamente:
crea los tramos del evento (Iglesia, Cena, Fiesta)
crea los accesos del evento (Solo Iglesia, Completo, etc.)
crea la matriz acceso-tramo
setea id_acceso_default en el evento
Backend responde
{ "ok": true }

Para el Acceso Default:
Además hay que setear el default. No lo hacemos “implícito” editando el acceso, ya que con el siguiente endpoint actualizamos ef_eventos.id_acceso_default. Le mandamos el id que el usuario marcó como default en el radio button.
Estaría bueno pintar o resaltar la card que se marcó como “default”.
Con esta condición:
Checked si acceso.id_acceso === estructura.id_acceso_default
Ejemplo: si id_acceso_default = 10, la card cuyo id_acceso = 10 aparece seleccionada.

Endpoint:

(dejé el endpoint en la carpeta “Evento - Tramos - Accesos - Relaciones (con Plantilla)”)
